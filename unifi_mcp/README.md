# Home Assistant Add-on: UniFi MCP

The [UniFi MCP](https://github.com/sirkirby/unifi-mcp) servers and Cloud Relay
bundled as a Home Assistant add-on, so cloud agents such as Claude can reach
your UniFi consoles without exposing any ports.

See the [Documentation](DOCS.md) for setup.
