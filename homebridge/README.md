# Unofficial Home Assistant Add-ons: Homebridge

Homebridge (<https://github.com/homebridge/homebridge>) bundled as a Home
Assistant add-on, using the official
[homebridge/homebridge](https://hub.docker.com/r/homebridge/homebridge) image.

## Installation

1. Navigate in your Home Assistant frontend to **Settings → Add-ons → Add-on
   Store**
1. Add this repository by URL
   (`https://github.com/tomwilkie/home-assistant-addons`)
1. Find the "Homebridge" add-on and click on it.
1. Click on the "INSTALL" button
1. Read the [Documentation](DOCS.md) inside the add-on
